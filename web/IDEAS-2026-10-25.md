# Ideas bank, 2026-10-25 (creative-director brainstorm)

Status: **PROPOSAL, not approved.** Nothing here is built until Tuhin picks.
Read with: `CHECKPOINT.md` (v6), `BENGAL-MOTIF.md`, `AI-PAGE-SCOPE.md`, `audit/rea-2026-10-19/SYNTHESIS.md`.

Rules every idea was checked against:
- **No fabricated facts.** Ideas run only on real feeds (Spotify, GitHub, Medium RSS, photo EXIF, StatsBomb Open Data, public APIs), the visitor's own input/session, or content Tuhin has confirmed.
- One screen, no scroll. Max one wow per page (SYNTHESIS P1: one device carries the page). The site-wide wow stays the molecule to chart world switch.
- Transform + opacity only, no per-frame full-page work, house ease `cubic-bezier(.19,1,.22,1)`, durations from `motionTokens`.
- Every idea lists its reduced-motion and touch fallback inside "build".
- Sound stays opt-in (R2 decision) unless noted.

Effort: S = under a day, M = 1-3 days, L = 4+ days. Risk = the main thing that could go wrong.

## A. Interaction devices

### 1. Contact Sheet to Scatter Plot
- **Experience:** On the film contact sheet, a small toggle "count them" makes every frame slide (FLIP) into a scatter plot of its real EXIF: x = focal length, y = shutter speed, dot size = ISO. The artist's photos literally become the analyst's data, and clicking a dot still opens the lightbox.
- **Build:** EXIF is already extracted for the lightbox shot-data strip; compute target positions once, animate thumbnails with framer-motion `layout` (FLIP, transform only); reduced motion = instant cross-fade; touch = same toggle, tap targets kept at 44 px.
- **Effort:** M. **Risk:** frames with missing EXIF need an honest "no data" gutter, not a guessed position. **Page:** Gallery (this IS Gallery's one wow; resolves the stepper vs print-strip question differently).

### 2. Through-ball navigation
- **Experience:** On the Analyst Home index, the visitor can grab the orange ball and flick it; a dashed pass line (kantha stitch) predicts its path and the row it reaches opens. Plain clicks on rows still work, so the flick is a bonus, not a gate.
- **Build:** pointer-down on ball, record last 80 ms velocity, ray-cast against row rects, animate ball with the existing `damp` helper; reduced motion and touch = rows only, ball stays decorative.
- **Effort:** M. **Risk:** discoverability; needs a one-time "flick me" hint in the readout (`→ FLICK n=00`). **Page:** Analyst Home.

### 3. The Kantha path (visitor's own thread)
- **Experience:** A thin running-stitch thread in the margin gains one stitch, in that page's motif colour, for every page the visitor opens. On Contact the thread finishes into a small embroidered signature of their route ("Gallery, Sound, Skills, Contact") that they can attach to their message.
- **Build:** route list in `sessionStorage`, SVG path with `stroke-dasharray` grown on route change; nothing leaves the browser unless the visitor sends the form; reduced motion = stitches appear without draw-on.
- **Effort:** M. **Risk:** must not feel like tracking; copy says "your thread, stays on your device". **Page:** global margin + Contact (both worlds).

### 4. Cross-world echo ("then he counted" made literal)
- **Experience:** Whatever the visitor last looked at in the artist world reappears counted in the analyst world: open frame 14 in the lightbox, switch worlds, and the Analyst Home readout says `LAST WATCHED → frame 14 · 1/60s · f/1.5 · ISO 80`. The story spine stops being a tagline and becomes a mechanic.
- **Build:** extend the existing `pointerMemory` module with a `lastWatched` record (photo id + EXIF, track, post); render through the existing counted-in Headline digits; reduced motion = static text.
- **Effort:** S. **Risk:** empty state on a cold visit; fall back to "nothing watched yet. go look." **Page:** world switch, Analyst Home.

## B. Data as art

### 5. Listening Alpona
- **Experience:** On Hostel Radio, a rice-paste alpona slowly draws itself from Tuhin's real recent plays: one petal per play, petal angle = time of day it was played, petal length = track duration. The pattern is different every day because it is literally the last 50 plays.
- **Build:** existing live Spotify feed (recently-played endpoint only; audio-features is deprecated for new apps, so do not rely on tempo/energy), radial SVG generated once per fetch, stroke draw-on 1000 ms; reduced motion = drawn instantly.
- **Effort:** M. **Risk:** Spotify token refresh on a static host needs the serverless proxy; private listening becomes public, so Tuhin must opt in. **Page:** Sound.

### 6. Commit Kantha
- **Experience:** Tuhin's real GitHub contribution calendar is stitched as kantha: each day one running stitch, stitch length = commit count, empty days are bare cloth. Hovering a stitch reads out the date and count in the analyst crosshair readout.
- **Build:** GitHub GraphQL `contributionsCollection` fetched at build time (or Netlify function with token in env), rendered as static SVG; no animation needed beyond a one-time draw-on.
- **Effort:** M. **Risk:** private-repo work hides as gaps; caption must say "public + counted contributions only". **Page:** Work or Journey rail.

### 7. When he watches (golden-hour dial)
- **Experience:** A small 24-hour sun dial shows when Tuhin's photos were actually taken, from EXIF timestamps: a thick terracotta arc around golden hour would be a real, discovered habit, not a claim. Hovering a slice filters the contact sheet to that hour.
- **Build:** bucket existing EXIF `DateTimeOriginal` by hour at build time, SVG arcs, filter via state; no GPS ever read.
- **Effort:** S. **Risk:** if the data shows no pattern, the dial still tells the truth; do not write copy before seeing it. **Page:** Gallery info panel (quiet, not a second wow) or artist About.

### 8. Live Match State
- **Experience:** Match Day reacts to Barça's real fixture: countdown before kick-off, a live score in the corner during the match (the ball pointer gets a tiny live dot), final score stamped like a ticket after. Between matches it rests on the Messi data portrait.
- **Build:** football-data.org free tier (La Liga is included) through a cached serverless function polled every 60 s only while the tab is visible; reduced motion = no pulse.
- **Effort:** M. **Risk:** API key and rate limits; must degrade silently to the portrait. **Page:** Match Day.

### 9. Field Notes strata
- **Experience:** The Field Notes index is drawn as a cut-away of sediment layers: one layer per post, thickness = real reading time, colour = tag, newest on top. Hovering a layer lifts it like a core sample and shows title + date, so 30 posts fit one screen without scroll.
- **Build:** Medium RSS + local posts merged at build time, layers as flex rows with heights from minutes, hover = translateY; reduced motion = no lift, underline instead.
- **Effort:** S-M. **Risk:** with many posts layers get thin; group by month past 40. **Page:** Field Notes.

## C. Sound

### 10. Real-shutter clack
- **Experience:** In the lightbox, the shutter sound is synthesised from that photo's real exposure time: 1/4000 s is a sharp tick, 1/15 s is an audible open-and-close. Visitors who notice it realise every frame sounds like the moment it was taken.
- **Build:** the WebAudio shutter synth from BENGAL-MOTIF §4 gets a gap parameter = mapped exposure time (clamped 20-400 ms); no assets; muted by default per R2.
- **Effort:** S. **Risk:** basically none; missing EXIF falls back to the default clack. **Page:** Gallery lightbox.

### 11. Sonified scorecard
- **Experience:** Each of the 5 Dashboard KPIs has a small "listen" control that plays its sparkline as a pitch sweep, with a click on the drill-through point. It doubles as an accessibility feature and quietly proves he thinks about how data is consumed.
- **Build:** WebAudio oscillator ramping frequency through the series values over 1.2 s; keyboard reachable; opt-in only.
- **Effort:** S. **Risk:** gimmick if over-explained; one icon, one tooltip. **Page:** Dashboard.

### 12. Goa weather radio
- **Experience:** Hostel Radio's room tone follows the real weather in Goa right now: rain on a tin roof when it is raining, ceiling fan hum when it is hot, nothing extra when it is mild. A tiny line says "Goa, now: 29°, rain" so the visitor knows it is real.
- **Build:** Open-Meteo (no key) fetched once per visit, picks one of three synth beds layered under the existing radio; reduced motion unaffected (audio only, still opt-in).
- **Effort:** S-M. **Risk:** it reveals city-level location, which Tuhin already states publicly (lives in Goa); no finer location. **Page:** Sound.

### 13. Chord of the visit
- **Experience:** Every page the visitor opens adds one note of a pentatonic scale to their session; on Contact, if sound is on, their whole route plays back as a short chord before the form. Pairs with the Kantha path (idea 3): one thread you see, one you hear.
- **Build:** same `sessionStorage` route list, WebAudio plucked-string synth; opt-in.
- **Effort:** S (if 3 exists). **Risk:** easy to make annoying; once per session, under 1.5 s. **Page:** Contact.

## D. The Bankura horse (mascot behaviour)

### 14. The grazing horse
- **Experience:** After 20 seconds without input, the terracotta horse walks into the margin and nibbles the alpona border, leaving a visible bite; the moment the visitor moves, it trots off and the border regrows. It rewards people who linger, which suits a photographer's site.
- **Build:** one SVG sprite sheet with CSS `steps()`, idle timer, border bite = clip-path on the alpona SVG; reduced motion = horse appears standing, no walk; touch = same idle timer.
- **Effort:** S-M. **Risk:** counts as one of the ≤8 loops; must stop on tab hidden. **Page:** artist world global.

### 15. Honest feed horse
- **Experience:** Whenever a live feed loads (Spotify, GitHub, Medium, papers), the horse trots in proportion to real fetch progress. If a feed fails it sits down and the card says "feed asleep, last seen 3 Oct", never a fake placeholder.
- **Build:** shared `useLiveFeed` status (loading / ok / stale / error) drives a small horse component; stale date from cached payload.
- **Effort:** S-M. **Risk:** low; it turns the mascot into proof that data is real. **Page:** every live-data card, both worlds.

### 16. Panchmura kiln
- **Experience:** On a first visit the horse is raw grey clay; as the visitor explores more of the site it is "fired" step by step toward full terracotta, with a faint kiln glow when it turns. It is a progress bar disguised as Bankura craft.
- **Build:** pages-seen / total from session, CSS colour interpolation between `--clay` and `--terracotta-500` on the horse SVG fill; no animation loop.
- **Effort:** S. **Risk:** must not imply a reward scheme; purely cosmetic. **Page:** global (horse in header/footer).

## E. Recruiter-facing proof of skill

### 17. Show the query
- **Experience:** Every number on the Dashboard and Work case files has a small "how counted" flip; the card turns over and shows the actual SQL or pandas snippet, the source and the refresh time. A BI recruiter sees the craft, not just the result (SYNTHESIS P2).
- **Build:** store real snippets next to each KPI definition in the existing data file, CSS 3D flip (transform only), syntax-highlight with a tiny highlighter at build time; reduced motion = swap without flip.
- **Effort:** S-M. **Risk:** snippets must be the real code used; if not available, the card says "definition only", never an illustrative fake. **Page:** Dashboard, Work.

### 18. Bring your own CSV (first look)
- **Experience:** A visitor drops a small CSV and in three seconds gets Tuhin's "first look": row/column counts, null map, one distribution and one correlation, laid out the way he would brief a team. Nothing uploads; it runs in their browser.
- **Build:** lazy-loaded PapaParse + hand-written profiling (no DuckDB-WASM, too heavy), 1 MB cap, three small SVG charts.
- **Effort:** L. **Risk:** bundle weight and edge-case files; strict lazy chunk, clear size limit. **Page:** AI in Practice page or Skills.

### 19. Job-description lens
- **Experience:** A recruiter pastes a JD; the Skills lenses and Work cases that have real evidence light up with links, and requirements with no evidence are listed plainly as "not shown here". Honest gaps are more convincing than a perfect match.
- **Build:** client-side keyword/synonym map over existing confirmed content only (no LLM, no network), highlights via state.
- **Effort:** M. **Risk:** overclaiming through loose synonyms; synonym map must be reviewed by Tuhin. **Page:** Résumé or Skills.

### 20. This site's own build ledger
- **Experience:** The AI in Practice page shows live facts about this very site: commit count, test count (currently 99/99), bundle size, last deploy, and a ledger of which commits were AI-assisted vs decided by Tuhin. The portfolio becomes its own case study.
- **Build:** GitHub API + CI artifact JSON (vitest count, bundle stats) at build time; the AI/human split only from real commit trailers, if they exist.
- **Effort:** M. **Risk:** if commit trailers were not kept, show only the counts; never estimate the split. **Page:** AI in Practice.

## F. Playful easter eggs

### 21. Console letter
- **Experience:** Anyone who opens DevTools sees an ASCII Bankura horse and one line: "you looked under the hood, so do I", plus the repo link. Engineers and technical recruiters remember this.
- **Build:** one `console.log` with styled `%c` in `main.tsx`, production only.
- **Effort:** S. **Risk:** none (conflicts with the "no console.log" lint rule; whitelist this one line). **Page:** global.

### 22. Visca
- **Experience:** Typing "visca" anywhere makes the alpona borders briefly take blaugrana stripes and the ball pointer do one keepy-uppy, then everything returns. Quiet, only for people who know.
- **Build:** global keydown buffer, a CSS class toggled for 1.5 s; reduced motion = colour change only.
- **Effort:** S. **Risk:** low; R2 bans the crest, stripes are fine. **Page:** global.

### 23. 404 penalty
- **Experience:** The 404 page is a single penalty: the visitor clicks where to shoot and the keeper dives according to Messi's real penalty placement distribution from StatsBomb Open Data. Win or lose, a button takes them home.
- **Build:** precomputed placement histogram (build-time script over StatsBomb JSON), SVG goal, one tween; attribution line required.
- **Effort:** M. **Risk:** the data is about Messi, not Tuhin; label it clearly. **Page:** 404.

## G. Field Notes

### 24. Pressed-leaf daily papers
- **Experience:** Each day's papers arrive as pressed leaves in the open notebook: title, one "why it matters" tag, source. Leaves dry and fade over seven days (by real age), so the page always looks like it is being used.
- **Build:** existing daily papers feed (HF daily / arXiv), CSS filter `sepia` + opacity by age at render, max 9 leaves on screen.
- **Effort:** S-M. **Risk:** "why it matters" must come from Tuhin or be omitted; an auto-generated line must be labelled as auto. **Page:** Field Notes.

### 25. Revision margins (Medium mirror diff)
- **Experience:** Mirrored Medium posts show small margin marks wherever the site version was edited after the Medium version, like a proof-read manuscript. It shows that he revises his thinking, which is rare and real.
- **Build:** at build time hash paragraphs of RSS vs local markdown, mark differing paragraphs; no runtime cost.
- **Effort:** M. **Risk:** RSS truncation can create false diffs; compare only full-text posts. **Page:** Field Notes post view.
