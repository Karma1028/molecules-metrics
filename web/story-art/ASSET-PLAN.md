## 3. Beyond the cast
- GALLOP CYCLE: one 8-frame side-view gallop strip per look for HEAT and GHIBLI ("horse carries you between pages"). Pose sheets are not a cycle.
- SCENE PLATES for parallax (3 layers on magenta: far, mid, near props like temple arch, palm, goalposts, snow pines, UI columns), 1 set per look = 5 sets. Existing 5 backdrops stay as far layers.
- FIREFLY: slice sheet to sprites + perched, sleepy, burst (X1).
- PROPS (X2): tablet+chart, football, camera, notebook, laptop, mug, headphones.
- TEXTURES (seamless, 1 each): screentone/halftone, handmade paper, terracotta clay, snow, UI grid, alpona border strip. Alpona/motifs also as hand-made SVG.
- NOT generated: lettering, SFX text, panel frames, wipes (CSS/SVG/canvas); no text inside any image.

## 4. Motion without video
Pose-swap states: idle (breathe via transform), react (face swap), walk (pair-walk slides over parallax), cursor-follow (horse picks front/3-quarter/side from cursor angle), click (Tuhin kick + dust FX), live feed (horse mood by real data: Barca result, listening, quiet). Reduced motion = static pose. Video (Veo) only after kit locked, with user OK per batch.

## 5. Quality gates for every sheet
Count figures, same man/same horse across sheets (Haiku contact-sheet review), no crop, magenta clean, sparkle erased, webp budget (cut-out <=120 KB, total lazy-loaded <=25 MB), meaningful alt text, honest labels (scripted vs live).
